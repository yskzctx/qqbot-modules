## 1. 快速开始：5 分钟写第一个模块

### 第一步：建文件

在机器人的 `QQBotData\modules\` 文件夹下新建一个 `.py` 文件，文件名就是模块名（建议英文，如 `my_first.py`）：

```python
MODULE_INFO = {"name": "我的第一个模块", "description": "回复 /hello 命令", "version": "0.1"}


async def on_event(bot, event):
    if event.get("post_type") != "message":
        return
    if event.get("raw_message") == "/hello":
        await bot.send_group_msg(event["group_id"], "Hello, World!")
```

### 第二步：保存

什么都不用点——框架每 3 秒扫描一次 modules 文件夹，**保存后几秒内自动加载**。
（也可以在面板「概览」页点「重载模块」立即生效。）

### 第三步：测试

用任意 QQ 给机器人发 `/hello`，收到 "Hello, World!" 即成功。

> 恭喜，你已经是一个机器人开发者了。下面章节教你框架的全部能力。

## 2. 工作原理：一条消息的旅程

```
好友/群友发消息
    ↓
QQ 本体（NTQQ）
    ↓  NapCat 注入其中，把消息转成 OneBot 11 标准事件
NapCat ──WebSocket──→ 框架核心（QQBot.exe）
    ↓                   框架核心不做任何业务，只做三件事：
事件管道                ① 收发 OneBot 协议  ② 加载模块  ③ 提供面板/AI/存储
    ↓ 按优先级依次经过每个模块
你的模块
    ↓ 调用 bot.send_group_msg(...) 等
回复消息 → NapCat → QQ → 对方屏幕
```

关键结论：

- **框架没有任何内置功能**，能做什么全看装了什么模块
- 模块之间是**管道关系**：事件按优先级依次流过，前面的模块可以拦截事件
- 模块运行在框架进程内，**Python 标准库全部可用**（文件、网络、定时、子进程……）

## 3. 模块文件规范

| 规则 | 说明 |
|---|---|
| 一个 `.py` = 一个模块 | 文件名即模块标识（数据存储、配置界面都按文件名关联） |
| 可选同名 `.html` | 存在则成为该模块在面板中的配置界面（见第 10 节） |
| `_` 开头不加载 | `_utils.py` 这类工具文件放模块目录里可被 `import`，但不会当模块 |
| 改了就热重载 | 新增/删除/修改内容，框架 3 秒内自动重载 |
| 编码 UTF-8 | 请始终以 UTF-8 保存 |

模块内可定义的全部成员（**全部可选**，按需使用）：

```python
MODULE_INFO = {"name": "显示名", "description": "一句话描述", "version": "1.0"}
PRIORITY = 100                        # 事件处理优先级，越小越先（默认 100）

def register(app): ...                # 框架启动/模块加载时调用一次
async def on_event(bot, event): ...   # 每个 OneBot 事件都会进来
def on_config(app, config): ...       # 面板保存本模块配置时回调
def on_unload(app): ...               # 模块被重载/卸载前调用（清理线程、连接）

from framework.plugins import cmd, api, event   # 装饰器（见第 5 节）
```

## 4. 生命周期钩子

### register(app) —— 加载时

```python
def register(app):
    app.log.info("我的模块上线了")       # app 即框架核心对象
    # 适合：初始化资源、启动后台线程
```

### on_config(app, config) —— 配置变更时

用户在面板保存本模块配置后触发，`config` 是保存后的完整配置字典。

### on_unload(app) —— 卸载前

模块热重载或框架退出前调用。**如果你启动了后台线程，必须在这里停止它**，否则线程会残留：

```python
_thread = None

def register(app):
    global _thread
    _thread = MyWorker()
    _thread.start()

def on_unload(app):
    _thread.stop()   # 务必实现优雅停止
```

### on_event 的返回值 —— 拦截事件

`on_event` / `@event` 处理函数 `return False` 可以**拦截事件**：排在后面的模块将收不到这条事件。
用于：敏感词过滤、防诈骗拦截、命令独占等场景。

## 5. 装饰器 API 详解

三种装饰器从 `framework.plugins` 导入，让代码更简洁：

```python
from framework.plugins import cmd, api, event
```

### @cmd(name, admin=False) —— 聊天命令

```python
@cmd("天气")
async def weather(bot, event, args):
    # 消息 "天气 北京" -> args = ["北京"]
    city = args[0] if args else "北京"
    await bot.send_group_msg(event["group_id"], f"{city}的天气是晴天")
```

- 触发规则：消息 **等于** name，或以 `name + 空格` 开头（剩余部分按空格切成 args 列表）
- `admin=True`：仅 `permissions.admins` 中的 QQ 号可触发，其他人触发时机器人回复"该命令仅管理员可用"
- 多个命令有包含关系时（如 `积分` 与 `积分排行`），**长命令优先匹配**

### @event(post_type=None, priority=100) —— 事件订阅

```python
@event(post_type="notice", priority=10)
async def on_notice(bot, event):
    # 只收 notice 类事件；priority 越小越先执行
    ...
    return False   # 返回 False = 拦截，后续订阅者不再收到此事件
```

- 不传 `post_type` 则接收所有事件
- 返回 `False`（且仅 `False`）拦截事件流

### @api(method, path) —— 模块自有 HTTP 接口

```python
@api("GET", "/stats")
async def stats(bot, request):
    # 挂载在 /api/m/<模块文件名>/stats，需面板会话令牌访问
    from aiohttp import web
    return web.json_response({"ok": True})
```

- 模块的 HTML 界面/外部系统可以直接调用，适合做数据看板、回调接收等
- 完整路径：`/api/m/<模块文件名><path>`，例如模块文件叫 `my_mod.py`、path 为 `/stats`，则访问 `/api/m/my_mod/stats`

## 6. bot 对象参考手册

所有处理函数的第一个参数 `bot`，是与 QQ 交互的总入口：

| 方法 | 说明 |
|---|---|
| `bot.send_private_msg(user_id, message)` | 发私聊 |
| `bot.send_group_msg(group_id, message)` | 发群聊 |
| `bot.call_action(action, params)` | 调用**任意** OneBot 11 动作（万能透传） |
| `bot.get_stranger_info(user_id)` | 查陌生人资料（昵称等） |

| `bot.delete_msg(message_id)` | 撤回一条消息 |
| `bot.is_admin(user_id)` | 是否管理员（读核心配置） |
| `bot.app` | 框架核心对象，见下 |

`bot.app` 上的常用成员：

| 成员 | 说明 |
|---|---|
| `bot.app.get_module_config(name)` | 读本模块数据（返回 dict） |
| `bot.app.set_module_config(name, cfg)` | 写本模块数据（自动落盘 JSON） |
| `bot.app.ai.chat(messages)` | 调用 AI（面板「AI 配置」中配置的 OpenAI 兼容接口） |

```python
await bot.send_group_msg(gid, "早上好")

await bot.send_group_msg(gid, [
    {"type": "text", "data": {"text": "注意看"}},

    {"type": "image", "data": {"file": "https://example.com/pic.jpg"}},
```

## 7. 事件结构速查

`on_event(bot, event)` 的 `event` 是 OneBot 11 标准事件（dict）。最常用的字段：

### 消息事件（post_type = "message"）

```json
{
  "post_type": "message",
  "message_type": "group",          // group=群聊 / private=私聊
  "group_id": 123456,                // 群聊才有
  "user_id": 10001,                  // 发送者 QQ
  "raw_message": "签到",             // 原始消息文本（含 CQ 码）
  "message": [                       // 段结构（推荐用这个判断 @、图片等）
    {"type": "at", "data": {"qq": "123456"}},
    {"type": "text", "data": {"text": " 你好"}}
  ],
  "sender": {"nickname": "小明", "user_id": 10001},
  "message_id": 12345                // 用于撤回等操作
}
```

### 通知事件（post_type = "notice"）

| notice_type | 含义 | 关键字段 |
|---|---|---|
| `group_increase` | 有人进群 | group_id, user_id |
| `group_decrease` | 有人退群 | group_id, user_id, operator_id |
| `group_recall` | 群消息被撤回 | group_id, user_id, operator_id |
| `group_upload` | 群文件上传 | group_id, file |
| `group_admin` | 管理员变动 | group_id, user_id, sub_type(set/unset) |
| `group_sign` | 群打卡签到 | group_id, user_id |
| `notify`/`poke` | 戳一戳 | target_id, sub_type |
| `notify`/`lucky_king` | 红包运气王 | target_id |
| `notify`/`honor` | 群荣誉变更（龙王等） | group_id, honor_type |
| `essence` | 精华消息变更 | group_id, sub_type |

### 请求事件（post_type = "request"）

| request_type | 含义 | 处理动作 |
|---|---|---|
| `friend` | 加好友请求 | `set_friend_add_request`(flag, approve) |
| `group` | 加群请求/邀请 | `set_group_add_request`(flag, sub_type, approve) |

```python
@event(post_type="request")
async def on_request(bot, event):
    if event.get("request_type") == "friend":
        await bot.call_action("set_friend_add_request",
                              {"flag": event["flag"], "approve": True})
```

### 元事件（post_type = "meta_event"）

心跳、生命周期事件，一般不用处理。

> NapCat 还会推送一些扩展事件（群打卡、戳一戳等），结构以收到的原始 JSON 为准——
> 在面板「实时事件流」里看一眼就知道字段了。

### 判断工具示例

```python
def at_me(event) -> bool:
    msg = event.get("message")
    if isinstance(msg, list):
        return any(seg.get("type") == "at" for seg in msg if isinstance(seg, dict))
    return "[CQ:at" in str(msg or "")
```


## 9. 数据存储规则

**核心原则：模块数据一律存 `QQBotData\data\<模块文件名>.json`，由核心统一读写，绝不回写模块文件。**

```python
# 读（不存在时返回空 dict）
cfg = bot.app.get_module_config("my_mod")

# 写（自动保存 + 触发 on_config 回调）
cfg["count"] = cfg.get("count", 0) + 1
bot.app.set_module_config("my_mod", cfg)
```

- 面板中该模块的配置界面读写的就是这份数据
- 热重载/升级框架/替换模块文件，数据都安全保留
- 需要大量结构化存储（如几千条记录）时，也可以在数据目录里自建 SQLite：

```python
import sqlite3, os
from framework.paths import DATA_STORE_DIR
db = sqlite3.connect(os.path.join(DATA_STORE_DIR, "my_mod.db"))
```

## 10. 配置界面（.html）开发

模块目录下放一个**同名 `.html`**（如 `my_mod.py` + `my_mod.html`），面板「模块」页选中该模块时就会展示它。

### 工作机制

- 面板以 iframe 加载 `/api/modules/<文件名>/ui?token=<会话令牌>`
- 界面 JS 从 `location.search` 取 `token`，调用两个接口读写自身数据：

```js
const token = new URLSearchParams(location.search).get("token") || "";
const base = "/api/modules/my_mod/config";
const H = {"Content-Type": "application/json", "X-Access-Token": token};

const cfg = await (await fetch(base, {headers: H})).json();          // 读
await fetch(base, {method: "POST", headers: H,
                   body: JSON.stringify({config: {...}})});           // 写
```

### 最小可用模板

```html
<!DOCTYPE html>
<html lang="zh-CN"><head><meta charset="UTF-8">
<style>
  body { font-family: "Microsoft YaHei", sans-serif; color: #e6edf3; padding: 6px 2px; }
  input, textarea { width: 90%; max-width: 460px; background: #212a33; color: #e6edf3;
    border: 1px solid #2c3742; border-radius: 8px; padding: 9px 12px; font-size: 13px; }
  button { background: #4c8dff; color: #fff; border: 0; border-radius: 8px;
    padding: 8px 18px; cursor: pointer; margin-top: 12px; }
</style></head>
<body>
  <label>我的配置项</label>
  <input id="my_field">
  <br><button onclick="save()">保存</button>
  <div id="tip"></div>
<script>
const token = new URLSearchParams(location.search).get("token") || "";
const base = "/api/modules/my_mod/config";
const H = {"Content-Type": "application/json", "X-Access-Token": token};
load();

  const c = await (await fetch(base, {headers: H})).json();
  document.getElementById("my_field").value = c.my_field || "";
}
async function save(){
```

## 15. 定时任务

模块没有内置定时器，标准做法是**后台线程 + 投递回事件循环**（参考 `modules/scheduled_msg.py`）：

```python
import asyncio, threading, time

_loop = None

def register(app):
    global _loop
    _loop = asyncio.get_running_loop()   # 框架主循环

def worker(bot):
    while True:
        time.sleep(60)
        asyncio.run_coroutine_threadsafe(bot.send_group_msg(123, "整点报时"), _loop)

def on_unload(app):
    pass  # 停止线程（配合 threading.Event 做优雅退出）
```

完整实现（含去重、异常处理、优雅退出）直接抄 `scheduled_msg.py`。

## 16. 实战：从零写一个"群管理"模块

需求：管理员发送 `踢 @某人`、`禁言 @某人 10` 时执行对应管理操作。

**第一步**：建 `group_admin.py`：

```python
from framework.plugins import cmd
import logging
log = logging.getLogger("group_admin")

MODULE_INFO = {"name": "群管理", "description": "踢人/禁言（仅管理员）", "version": "1.0"}


def _at_target(event) -> int | None:
    """从消息段里取出被 @ 的人的 QQ 号。"""
    for seg in event.get("message") or []:
        if isinstance(seg, dict) and seg.get("type") == "at":
            return int(seg["data"]["qq"])
    return None


@cmd("踢", admin=True)
async def kick(bot, event, args):
    target = _at_target(event)
    if not target:
        await bot.send_group_msg(event["group_id"], "用法：踢 @某人")
        return
    await bot.call_action("set_group_kick",
                          {"group_id": event["group_id"], "user_id": target})
    await bot.send_group_msg(event["group_id"], f"已将 {target} 请出本群")


@cmd("禁言", admin=True)
async def ban(bot, event, args):
    target = _at_target(event)
    duration = int(args[0]) * 60 if args and args[0].isdigit() else 600
    if not target:
        await bot.send_group_msg(event["group_id"], "用法：禁言 @某人 分钟数")
        return
    await bot.call_action("set_group_ban",
                          {"group_id": event["group_id"],
                           "user_id": target, "duration": duration})
    await bot.send_group_msg(event["group_id"], f"已禁言 {target} {duration // 60} 分钟")
```

**第二步**：放入 `QQBotData\modules\`，等热重载。

**第三步**：群里发 `踢 @某人` —— 完成。

这个例子演示了全部核心概念：命令装饰器、权限、段结构解析、call_action 透传、
错误提示。你现在的水平已经足够写出自己的机器人了。

## 18. 常见问题 FAQ

**Q: 模块能多开吗？同一个框架能跑多少模块？**
A: 理论无上限。模块按文件独立加载，互不影响（除非你在事件管道里拦截）。

**Q: 两个模块都想响应"签到"怎么办？**
A: 都用 `@cmd("签到")` 会冲突（后加载的覆盖前者）。用不同的命令名，或一个模块内处理。

**Q: 框架重启后模块数据会丢吗？**
A: 不会。数据在 `QQBotData\data\`，与模块文件、框架升级完全无关。

**Q: 能读写机器人以外的文件吗？**
A: 能。模块运行在框架进程内，标准库全开放（见第 13 节）。但请对自己的操作负责。

**Q: 怎么让别人也用我的模块？**
A: 把 `.py`（和 `.html`）发给对方放进 modules 文件夹即可。欢迎 PR 到本仓库分享。

**Q: 模块会拖慢 QQ 吗？**
A: 处理函数是异步并发的，但单个函数内的耗时操作（大文件读写、长睡眠）会阻塞管道，
   请用 `asyncio.to_thread` 或后台线程处理重活。
